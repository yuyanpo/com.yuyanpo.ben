# Ben 产品需求文档

- 产品名称：Ben；Bundle Identifier：`com.yuyanpo.ben`
- 平台：原生 macOS 应用，最低 macOS 15
- 起始版本：0.0.1（构建号 1）
- 开发阶段：只构建和运行 Debug，分发阶段再处理 Release、公证与升级

## 产品定位

轻量的 macOS 翻译工具。围绕「选中文字 → 按 Option + C → 查看译文」提供菜单栏浮窗，也支持手动输入。使用 Swift、SwiftUI、AppKit 和 URLSession，不引入 Electron 或 WebView。

当前提供微软、谷歌翻译 API 和 B站 Index-Translate 大模型，默认微软，用户在设置中手动选择并记住偏好。移除 Apple 本地翻译及语言模型下载流程，翻译需要联网。

## 取词与语言

1. 快捷键触发时先记录鼠标位置、读取前台选区，再显示 Ben，避免激活后丢失选区。
2. 使用 `AXUIElement` 读取焦点元素和选中文字，必要时通过选区范围读取文本；不扫描整个文档、不读取安全输入字段。
3. 无权限、无选区、不支持读取、空文本和超长文本提供明确提示；不读取陈旧剪贴板假装取词成功。
4. 去除首尾空白，限制为 5,000 个 Swift Character；超限不静默截断。
5. 自动方向下中文译英文，其余语言译简体中文。最多 3 个词、40 个字母且字母全部为 ASCII 的短文本优先按英语处理，更长及非 ASCII 文本使用系统语种识别。数字和标点不强行指定语种。
6. 面板可手动纠正原文语种；已有结果或请求时，纠正后重译。新捕获选区恢复自动识别。原文已是目标语言时直接返回原文并说明，不发网络请求。

VS Code、Cursor 的代码编辑区未提供辅助功能选区时，调用该应用的「复制」菜单，最多等待 650ms。本次剪贴板必须发生变化且包含编辑器的非空选区标记，拒绝无选区时默认复制整行。保存并恢复原剪贴板可读取的全部类型；无法完整保存或超过 16 MiB 时放弃兜底，用户再次复制后不覆盖其新内容。仅由取词操作触发，捕获期间不激活 Ben，焦点变化或新请求取消捕获，不修改编辑器设置。

辅助功能权限在设置打开、返回应用、窗口获得焦点、主动刷新及取词前检查，不在空闲时轮询。手动输入不需要权限。启动不主动弹授权窗口，用户点击后才请求。

## 翻译服务

| 服务 | 接口 | 凭据 | 请求方式 |
| --- | --- | --- | --- |
| 微软翻译 | Microsoft Edge 翻译接口 | 当前无需 Key | HTTPS JSON 数组，转义原文的 HTML 特殊字符，响应只解码一层实体 |
| 谷歌翻译 | Google Translate 接口 | 当前无需 Key | HTTPS 表单；首接口临时失败时可使用另一 Google 协议重试 |
| B站翻译 | Index-Translate 公开免费 API | 当前无需 Key | Chat Completions，模型 `Index-Translate-35B-A3B`，非流式 |

服务实现统一异步协议，UI 不解析响应。请求包含唯一 ID、所选提供方、文本和语言；结果包含原文、译文、语言和提供方 ID。

- 只向选定提供方发送文本，服务失败时不自动改用其他提供方。
- 设置切换服务时取消当前请求、清除旧结果并保留输入；下次主动翻译生效，切换本身不发送文本。
- 谷歌仅在网络、超时、响应解析或临时服务错误时尝试同提供方的另一协议；鉴权拒绝和限流不重试。
- 微软单次请求期限 12 秒，谷歌最多两次各 5 秒，B站 30 秒；响应体最多 1 MiB。
- HTTP 429 按 Retry-After 暂停该服务的新请求；未提供时暂停 60 秒，缓存命中不受影响。
- 会话缓存最多 128 条且原文与译文总计不超过 1 MiB，以服务、原文、源语言和目标语言区分；仅内存保存，退出清空。
- 公开免费接口可能调整或限流，可用性取决于提供方及网络；不承诺永久免费或固定延迟。

大模型的系统指令与原文分离：要求忠实翻译、仅输出译文、保留段落、专有名词和代码，不执行原文指令。拒绝空响应、截断结果及不完整的思考标签；无法保证模型始终遵循指令。

## 面板与状态

- 在鼠标附近显示并复用同一浮窗，限制在屏幕可见区域；支持浅色和深色。
- 宽 400pt，由内容决定高度；输入区域 52–128pt，译文区域 24–220pt，超出后滚动。空状态不预留译文区域，加载及错误仅占实际高度。
- 顶部 Logo、标题和空白区域支持原生窗口拖动，使用四向箭头 move 光标；按钮、文字编辑和译文选择独立响应。
- 翻译期间显示当前服务和取消按钮；Esc、关闭按钮或外部点击关闭浮窗并取消请求。
- UI 状态在 MainActor 更新；新请求取消并替换旧请求，迟到结果和错误不得覆盖新结果。
- 原文左侧提供朗读、复制、清空图标，右侧显示选词与翻译快捷键；译文左侧提供朗读、复制图标。复制成功显示勾号，朗读中可停止；清空原文与译文并取消翻译和朗读。
- 朗读使用 macOS 系统语音。复制按钮仅在用户点击时修改剪贴板；编辑器取词兜底按前述规则临时使用剪贴板，空闲时不轮询剪贴板或选区。
- 菜单栏图标使用透明模板；应用图标使用纯白底与独立黑色 SVG 符号的 Icon Composer 格式。保留 reference 原始素材。
- 原生关于弹窗展示 Logo、名称和 Bundle 版本，简介仅「轻量的 macOS 翻译工具」。

## 数据与运行

原文、译文和凭据不得写入日志；不持久保存历史。使用无 Cookie、无磁盘缓存的临时网络会话。未来增加 API Key 时存入 Keychain，不写入 UserDefaults 或仓库。

保持单一原生菜单栏应用结构，空闲不持续监听文本、不预加载多个窗口。初始资源目标为空闲 CPU 小于 1%、进程物理内存 footprint 小于 100 MiB，须排除 Xcode 调试影响后实测。

开发使用固定 Apple Development 签名和 Debug 路径；签名身份变化可能影响辅助功能授权。正式分发再补充 Developer ID、公证和更新策略。当前不启用 App Sandbox。
