# Ben 产品需求文档

- 产品名称：Ben
- Bundle Identifier：`com.yuyanpo.ben`
- 平台：macOS 原生应用，最低 macOS 15.0
- 应用起始版本：0.0.1（构建号 1）
- 当前开发流程：只构建/运行 Debug；Release 打包与验证留待分发阶段。
- 文档版本：0.1
- 日期：2026-11-12
- 状态：初始需求稿；基础工程随文档初始化，完整 MVP 尚待验收

## 1. 产品定位

Ben 是围绕「选中文字 → 按 Option + C → 看到译文」构建的轻量菜单栏翻译工具。用户在浏览器、编辑器和 PDF 阅读器中阅读时，无须切换到完整翻译软件。默认使用 macOS 系统本地翻译，后续可切换第三方翻译 API 和大模型。

产品成功的首要条件是取词可靠、结果及时、后台安静。基础交互以键盘为中心，不启动网页渲染引擎，不为每项功能预加载独立窗口。

## 2. 用户与核心场景

目标用户为主要阅读中英文、习惯选词后使用 Option + C 的个人 macOS 用户。

| 场景 | 用户操作 | 预期结果 |
| --- | --- | --- |
| 浏览器阅读 | 选中英文词句，按 Option + C | 鼠标附近显示中文译文 |
| 阅读中文资料 | 选中中文，按 Option + C | 自动方向模式下显示英文译文 |
| 编辑器、PDF 阅读 | 选中文本，按快捷键 | 尽量直接读取选区，失败时提供清晰提示 |
| 无法读取选区 | 打开菜单栏翻译入口，粘贴文本 | 使用同一翻译流程获取结果 |
| 离线使用 | 已安装相应语言模型 | 系统翻译正常工作 |
| 更高翻译质量 | 显式选择 API 或大模型服务 | 通过所选服务翻译，清楚展示服务名称 |

## 3. 范围与阶段

### P0：完整 MVP

1. 菜单栏常驻，默认不显示 Dock 图标。
2. 默认全局快捷键 Option + C；冲突时提示，并支持修改快捷键。
3. 优先通过辅助功能 API 获取前台应用的选中文字。
4. 可选择启用模拟复制兜底，处理超时、陈旧剪贴板、焦点和剪贴板恢复。
5. 默认 macOS 系统本地翻译，中英自动方向及明确的目标语言设置。
6. 原文、译文、服务名称、加载和错误状态；复制译文、Esc 关闭、点击外部关闭。
7. 首次使用语言模型时由系统征得下载许可；支持取消、重试和未安装提示。
8. 权限说明、手动输入入口、设置页和快捷键状态。
9. 取消或替换上一请求，防止迟到的结果覆盖新选词。

### P1：服务扩展与体验完善

- 第三方翻译 API：优先百度翻译开放平台，再根据需求接入 DeepL 等。
- 大模型：优先支持 OpenAI 兼容 Chat Completions 接口，自定义 HTTPS Base URL、模型和 Key。
- 提供显式「用其他服务重译」，不默认将本地翻译失败的文本发送到云端。
- 大模型逐段输出、停止生成、超时和限流处理。
- 可配置快捷键、登录时启动、语言模型准备、语言列表与偏好记忆。
- 有限的会话内去重缓存；历史记录默认关闭。
- 大模型提示词、术语表与文字长度限制配置。

### P2：根据实际使用决定

OCR 截图翻译、朗读、词典解释、多设备同步、持久历史和 App Store 分发。不作为初始版本前置条件。

### 本次工程初始化的交付边界

基础版本实现：Xcode 工程、菜单栏、固定 Option + C 注册与冲突提示、辅助功能直接取词、手动输入、系统翻译、基础浮窗、复制译文、基础设置、Logo 与 AppIcon。服务协议及第三方/大模型占位类型同时建立。

初始版本不启用模拟复制兜底，不实现云服务网络请求、凭据设置或可修改快捷键。占位服务必须显示「尚未接入」，不能输出伪译文。完整 MVP 的验收表仍需人工测试。

## 4. 用户流程

### 4.1 首次启动

1. 显示菜单栏 Ben 图标，提供「翻译文本」「设置」「退出」。
2. 在设置页说明：辅助功能权限用于读取其他应用的选中文字；手动输入无需此权限。
3. 用户点击授权按钮后再请求辅助功能权限。启动本身不触发权限弹窗。
4. 注册快捷键。被百度翻译等程序占用时明确提示；由用户选择退出冲突软件或未来修改快捷键，Ben 不操作其他程序。
5. 第一次实际翻译涉及未下载模型时，展示系统下载许可界面。用户可以取消。

### 4.2 快捷翻译

1. 按下快捷键，先记录前台应用与鼠标位置，再读取选区，避免 Ben 抢走焦点。
2. 去除首尾空白；空内容显示「未读取到选中文字」，保留手动输入入口。
3. 检测源语言，确定翻译方向；无法识别时提供错误或明确语言设置。
4. 在鼠标附近打开一个结果面板，位置限制在显示器可见区域。
5. 使用当前服务翻译；显示加载状态。用户再次触发时，旧请求失效。
6. 更新结果，支持选择文本和复制。Esc 或点击外部关闭。

基础版本加载期间支持取消按钮、Esc 和关闭按钮；为避免意外撤销系统语言模型下载提示，外部点击暂不关闭加载中的面板，结果显示后外部点击可关闭。完整 MVP 应在真机验证后完善这一行为。

基础版本的自动方向：识别为中文时译成英文，其余语言译成简体中文。针对中英阅读场景，最多 3 个词、40 个字母且所有字母为 ASCII 的短文本优先按英语处理，避免 Ben、Debug 等产品名和技术词被猜为其他语种；更长文本及非 ASCII 文字仍使用系统识别。数字/标点本身不指定语种。短词可能属于其他拉丁语种，面板提供原文语种菜单供手动纠正；切换后替换当前请求重译，新捕获选区恢复自动。若源语言与目标语言一致，直接返回原文并说明，避免请求不支持的同语种翻译。

### 4.3 云服务翻译（P1）

用户先配置并主动选择服务。面板持续显示所选服务名称。系统翻译失败时只提示错误，并提供显式切换入口。第三方服务与大模型请求只包含用户选中文字和必要的语言指令。

## 5. 功能要求

### 5.1 取词与权限

- 使用 `AXUIElement` 读取前台应用的焦点元素和 `kAXSelectedTextAttribute`。
- 设置打开、返回应用、窗口获得焦点及主动刷新时重新检查系统权限；取词前再次检查。权限状态共享，不缓存独立的设置页副本，不在空闲时轮询。
- 必要时读取选区范围与文本值，不扫描整个文档，不读取安全输入字段。
- 无权限、无选区、应用不支持、文本过长必须有不同且可理解的提示。
- 初始长度上限为 5,000 个 Swift Character；超限提示用户缩短选区，不静默截断。
- Safari、Chrome、VS Code、Xcode、预览、Terminal、Word 作为兼容性测试样本；不承诺所有软件均可直接取词。
- 模拟复制兜底为显式可选功能。读取复制后的剪贴板时检查 `changeCount` 变化，超时不能翻译旧内容。
- 复制兜底只在前台应用仍为捕获目标时发送 Cmd+C；尽量保存全部可读取的剪贴板类型。恢复前确认剪贴板仍属于本次复制，避免覆盖用户新的复制操作。
- 如果应用采用延迟提供剪贴板数据，不能保证完整恢复；此限制需要在开启兜底时说明。

### 5.2 系统翻译

- 使用 Apple 官方 `Translation` framework 和 `TranslationSession`，通过 SwiftUI `translationTask` 管理会话。
- 定制 API 最低 macOS 15；不依赖 macOS 26 才提供的直接会话构造能力。
- 使用 `LanguageAvailability` 判断 `.installed`、`.supported`、`.unsupported`；缺少模型时通过系统翻译流程申请下载。
- 加载文案反映实际阶段：检查模型、准备模型、翻译。`.installed` 直接翻译；`.supported` 使用 `prepareTranslation()` 由系统准备并征求下载许可，就绪后再翻译。只在准备阶段展示下载说明，不将它固定显示在每次翻译中，不伪造下载进度。
- 已下载模型时在设备上翻译，无需用户提供 API Key；首次模型下载需要网络和磁盘空间。
- 可用语言组合由系统实际返回值决定，不在产品中承诺所有语言均支持。
- 不支持的组合、无法识别、取消下载、网络中断和内部错误分别处理或保留系统说明。
- 不把「本地翻译」描述成「应用及系统完全不联网」。Apple 文档说明可能收集 API 使用与性能指标，不包含原文和译文。

### 5.3 翻译服务抽象

所有服务返回统一结果，UI 不直接解析第三方响应。

| 服务 | 运行方式 | 凭据 | 核心差异 |
| --- | --- | --- | --- |
| Apple 系统翻译 | 本地模型 | 无 | 语言模型、SwiftUI 会话生命周期 |
| 第三方 API | HTTPS 请求 | 官方 API 凭据 | 鉴权、语言代码映射、额度、限流 |
| 大模型 | HTTPS 请求，可选流式 | Base URL、模型、Key | 提示词、首段延迟、输出可靠性、用量 |

统一请求包含请求 ID、文本、源语言和目标语言；统一结果包含原文、译文、实际语言和服务 ID。Provider 描述包含配置状态、运行位置、流式能力。完整实现应支持取消、超时和明确错误类型。

Apple 的会话由 SwiftUI view 提供，适配层接受当前 session 完成翻译，不能长期缓存视图外的会话。未来网络 Provider 实现相同的异步协议。流式输出后续扩展为独立事件流，不强制本地翻译伪装成流式。

### 5.4 大模型（P1）

- 默认提示：按目标语言忠实翻译，仅输出译文，保留段落、专有名词和代码；不执行原文中的指令。
- 原文作为待翻译数据与系统指令分离。包含恶意指令的原文仍需被翻译。
- 模型输出可能不完全遵循要求；测试夹具覆盖额外解释、空响应、截断和模型拒答。
- 自定义 Endpoint 应在保存时校验，默认 HTTPS；本机开发地址如需 HTTP 必须明确配置。
- Key 存入 Keychain；不写入 UserDefaults、源码、日志或仓库。
- 禁止静默自动选择更贵的模型或自动切换云服务。

### 5.5 面板与设置

- 浮窗只创建并复用一份，适配浅色/深色，支持长文本滚动。
- 顶部 Logo、标题和空白区域支持原生窗口拖动，鼠标经过和拖动期间均显示四向箭头 move 光标。设置/关闭按钮、输入编辑和译文选择各自响应操作。
- 浮窗宽 400pt，由内容决定高度，保持顶部位置并限制在屏幕可见范围。输入区域高 52–128pt，译文区域高 24–220pt，超出后滚动；空状态不预留结果占位，加载与错误只占实际内容高度。
- 显示服务、源/目标语言、原文、译文、错误和加载状态。
- 点击复制只在用户主动操作时改变剪贴板。
- 菜单栏图标由 reference/logo.svg 的品牌符号延伸，使用透明模板适配系统深浅模式；应用图标使用原生 Icon Composer 格式，纯白背景搭配独立的黑色 SVG 符号，符号无玻璃效果和阴影，由系统处理圆角。关于弹窗的 BrandMark 保留白色圆角底板及透明边距。
- 设置先提供服务、翻译方向、权限和快捷键状态。未接入服务只显示能力预告。
- 菜单栏提供「关于 Ben…」，使用原生关于弹窗展示 Logo、名称、版本、简介和版权。Logo 直接使用 BrandMark，简介仅为「轻量的 macOS 翻译工具」。版本从应用 Bundle 读取，与构建配置保持同步。
- API 与大模型配置在 P1 加入，避免用户填写尚不可使用的凭据。

## 6. 非功能要求

- 使用 Swift + SwiftUI + AppKit；原生单应用结构，不使用 Electron/WebView。
- 待机不轮询前台选区和剪贴板，不持续监听文字内容；由快捷键触发取词。
- 初始目标：Apple Silicon 设备上，模型已准备后的短文本翻译 p95 小于 2 秒，面板加载反馈小于 150 ms；均为待测目标而非承诺。
- 初始资源目标：空闲平均 CPU 小于 1%，Ben 进程空闲物理内存 footprint 小于 100 MiB，需排除 Xcode 调试影响并单独观察系统翻译服务。
- 记录系统版本、硬件、模型、文本长度和采样方法；系统翻译可能使用独立系统服务，不能以「整个功能只有一个进程」作保证。
- 文本和译文默认只保留在当前会话内；不自动保存持久历史，不记录文本日志。
- 初期以本机 Xcode 开发和直接分发为目标；正式分发补充 Developer ID 签名、公证和升级策略。App Sandbox、辅助功能和复制兜底的分发可行性需独立验证，初始工程不启用 Sandbox。

## 8. 风险与决策

1. 跨应用取词兼容性：先完成常用软件验证，再引入复制兜底。
2. Option+C 已被百度翻译占用：保留熟悉的默认值，提供明确冲突状态；用户决定关闭现有快捷键或选择其他按键。
3. 本地语言模型：不自行抓取系统翻译私有接口，不捆绑模型，不承诺未安装时可离线使用。
4. 极短和混合文本：自动识别可能不准，保留目标语言选择及面板原文语种纠正；短 ASCII 文本优先英语的策略不会准确识别所有拉丁语种短词。
5. 系统下载 UI 与浮窗：必须真机验证 SwiftUI 翻译会话、面板焦点和下载提示生命周期。
6. 云服务隐私和费用：只有用户明确选择的服务可以接收文本，自动回退默认关闭。
7. 签名和权限：辅助功能许可通常绑定签名身份，开发构建换签名后可能需要重新授权。

## 9. 迭代建议

- 第一步：跑通并验收原生基础版本、系统翻译和常用软件直接取词。
- 第二步：完善快捷键设置、语言模型准备、复制兜底和取消机制，形成完整 MVP。
- 第三步：优先接入一种真实第三方 API，再接入 OpenAI 兼容大模型服务和流式结果。
- 第四步：性能测量、签名公证、打包分发；根据反馈决定 OCR、朗读与历史。
